# Contributing / Katkı

Use Node 24.13+ (24.x). On a clean checkout run `npm ci --ignore-scripts`, `npm run check`, `npm audit --audit-level=low`. Keep private `.env` outside the checkout while checking. Never submit real credentials, private IDs or private musical content. Use fictional chord examples; report input/options, expected result, actual result and OS/Node version. Pull requests should state the behavior change and meaningful validation. Keep licenses reviewed, exact package versions, minimal permissions and cross-platform helpers.

Node 24.13+ (24.x) kullanın. Temiz checkout'ta `npm ci --ignore-scripts`, `npm run check`, `npm audit --audit-level=low` çalıştırın. Kontrol sırasında özel `.env` dosyasını checkout dışında güvenle tutun. Gerçek token, özel ID veya özel müzik içeriği göndermeyin. Uydurma örneklerle girdi/seçenek, beklenen/gerçek sonuç ve OS/Node sürümünü belirtin. PR davranış değişikliği ve anlamlı doğrulamayı anlatsın. Gözden geçirilmiş lisanslar, tam sürümler, düşük izinler ve platformlar arası yardımcılar korunsun.

Notation additions need an explicit grammar and independent pitch tests, including roots, basses, negative shifts and spelling. Privacy changes need updated README/PRIVACY. Do not add lyrics/audio downloading, message-content access, tracking or automatic public broadcasts. See SECURITY.md for vulnerability reporting.

Yeni notasyon açık gramer ve bağımsız perde testleri gerektirir: kök, bas, negatif kaydırma ve yazım. Gizlilik değişikliklerinde README/PRIVACY güncellensin. Söz/ses indirme, mesaj içeriği erişimi, takip veya otomatik toplu paylaşım eklemeyin. Güvenlik bildirimi için SECURITY.md'ye bakın.
